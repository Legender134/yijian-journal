# 宣传素材制作

宣传片从“拜师前还有什么不能错过”切入，沿一次真实操作展示流程、材料、地图、比武请教和存档。59 秒，1920 × 1080，30 fps；墨绿与纸色延续应用风格。

## 重建界面截图

```powershell
node scripts/capture-showcase.cjs .test-data/showcase
```

脚本启动实际应用，使用独立的示例进度，通过正常界面操作采集截图；不读取个人存档、不启动或附加游戏。输出目录必须是新目录。PNG 用于图片素材，WebP 用于 README。截图中的演示状态不代表作者的实际游戏进度。

## 录制连续操作

```powershell
node scripts/capture-promo.cjs .test-data/promo-take
```

录制脚本在独立示例进度中操作实际 Electron 窗口，保存界面变化的高分辨率帧、鼠标位置、点击时间及分段标记。镜头包括展开推进影响、悬停材料、点击获取地点进入地图、查看同一人物的私物和请教内容、创建并校验一份完整备份，最后收起随行。

记录通过后才标记完成；中途错误会保留已采集的本地记录。视频渲染器不接受未完成的录制。既不替换界面文字，也不使用截图切换伪造操作结果。

## 用代码生成视频

需要 Python 3.12+、Pillow、NumPy 和 FFmpeg。字体默认使用 Windows 自带的微软雅黑与楷体，也可用参数指定其他有权使用的字体文件。

```powershell
python scripts/create-promo.py --capture .test-data/promo-take --game <获授权采集的游戏片段.mp4> --out .test-data/promo-preview --preview-only
python scripts/create-promo.py --capture .test-data/promo-take --game <获授权采集的游戏片段.mp4> --out .test-data/promo-final
```

代码按分段标记剪去录制等待，保持点击与结果的先后关系；镜头推进、阅读停顿和鼠标轨迹都围绕当前操作。字幕只提示本步用途。配乐为原创程序合成，点击音与实际输入对齐，不采样游戏音乐，不依赖在线生成服务。

先检查分镜预览，再检查原速连续片段：鼠标是否点中目标、结果是否接着出现、地图与人物是否前后关联、放大时文字是否清楚、字幕是否遮挡操作结果。联系图仅用于构图检查，不能代替动态验收。输出包含 MP4、封面、联系图、音轨与制作记录，不覆盖已有输出目录。游戏原片需包含至少四秒的连续收尾画面。

游戏片段应在获得玩家许可后单独采集，检查完整画面，避开账户、聊天和其他程序。自动测试不得以录制宣传片为由启动或接入游戏。当前宣传素材中的游戏场景为实际采集，手札界面为示例进度，合成展示不作为原生存读档能力的验证证据。
